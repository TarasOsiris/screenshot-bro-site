# Entity facts — Screenshot Bro

The canonical description of the product. **Copy from here verbatim** for every
directory listing, profile, and press mention.

Why verbatim matters: language models build their picture of a product by
aggregating how it is described across many independent sources. Twenty listings
that describe Screenshot Bro in the same words produce a confident, consistent
answer; twenty that each paraphrase produce a vague one. Consistency is the
asset — not creativity.

## Feature list (for checkbox-style directory fields)

- Native Mac, iPad and iPhone app (macOS 15+, iOS/iPadOS 18+)
- App Store and Google Play screenshot sizes
- Device frames: iPhone, iPad, Mac, Android
- Multi-row layouts with backgrounds spanning several screenshots
- 50+ starter templates
- Text, shapes, gradients, images, SVG
- 81 language presets plus custom locale codes
- On-device auto-translate with translation progress tracking
- Per-shape locale overrides (text, position, size, image)
- Batch export PNG/JPEG organized by locale and row
- Direct App Store Connect upload (free tier included)
- Direct Google Play upload (free tier included)
- iCloud sync (opt-in, free tier included)
- Local MCP server on Mac — AI agents (Claude Code, Claude Desktop, Cursor) can drive the app
- Plain-JSON project files — https://screenshotbro.app/docs/project-schema
- Watermark-free exports on the free tier

## Positioning sentences (for "what makes it different" fields)

1. It is a native Mac, iPad and iPhone app, not a browser tool — it works offline and
   keeps project files on your disk.
2. The free tier exports without a watermark, so you can ship a small listing
   without paying anything.
3. The whole listing — every size, row, and locale — lives on one zoomable
   canvas rather than in one design per size.
4. Project files are plain JSON and publicly documented.
5. It uploads finished sets straight to App Store Connect and Google Play, on the
   free tier too.
6. It ships an opt-in local MCP server on Mac, so an AI agent can build, translate
   and export a whole set through the same undoable actions you use by hand.

## Rules

- Never claim features we don't have. We do **not** have: Apple Watch / TV /
  Vision Pro screenshot-size presets (an Apple Watch Ultra 3 *frame* exists, a
  watch *row size* does not), a hosted API or CLI (the in-app MCP server is local
  to the Mac), video or App Preview export, fastlane integration, import of other
  tools' project files, a Windows, Linux or web version, or a published price.
- Say "81 language presets plus custom codes", never "81+ languages". On-device
  auto-translate covers the languages Apple's Translation framework supports; the
  remaining presets are filled by typing or pasting. Competitors with machine
  translation into 80+ languages will correct anything looser.
- Store upload and iCloud sync are on the free tier. Pro only lifts the project /
  row / template limits — never describe upload as a Pro feature.
- Screenshots for listings: use the same set everywhere (see `public/` and the
  App Store listing) so the visual identity matches the text identity.
